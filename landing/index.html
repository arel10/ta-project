Sirkula dirancang untuk memudahkan setiap langkah — dari setor sampah hingga menukar reward.

Setor Sampah Digital

Ajukan setoran sampah langsung dari aplikasi. Pilih jenis sampah (Plastik, Kertas, Logam, Kaca, Organik, Elektronik), masukkan berat estimasi, dan tunggu konfirmasi petugas bank sampah.

6 Kategori Sampah Konfirmasi Real-time Riwayat Lengkap

Sistem Poin & Reward

Setiap kilogram sampah yang disetor menghasilkan poin. Tukar poin dengan beragam reward menarik — voucher, produk eco-friendly, hingga hadiah digital.

Poin Otomatis Reward Catalog

Leaderboard Komunitas

Bersaing secara sehat dengan anggota lain. Lihat posisi rankingmu dan termotivasi untuk menyetor lebih banyak demi lingkungan yang lebih bersih.

Ranking Real-time Top 10 Board

Misi & Gamifikasi

Selesaikan misi harian & mingguan untuk mendapatkan bonus poin ekstra. Kumpulkan badge dan naiki level sebagai bukti kontribusimu terhadap lingkungan.

Daily Missions Badge System

Analitik Berbasis AI

Machine learning menganalisis pola setoran untuk mendeteksi anomali dan menilai risiko partisipasi, memastikan integritas seluruh ekosistem bank sampah.

ML Risk Detection Smart Insights

Panel Admin Lengkap

Admin bank sampah mendapatkan dashboard komprehensif: manajemen anggota, validasi setoran, konfigurasi reward & misi, monitoring risiko, dan laporan statistik lengkap secara real-time.

📱

Mobile App

Aplikasi Android & iOS dibangun dengan Flutter menggunakan Material Design 3. State management dengan Provider pattern, navigasi dengan GoRouter.

  • ✦ Cross-platform (Android & iOS)
  • ✦ Smooth animations & transitions
  • ✦ Offline-capable architecture
🖥️

Admin Dashboard

Web app admin dibangun dengan Next.js 14 App Router, memberikan antarmuka yang responsif untuk manajemen operasional bank sampah.

  • ✦ Next.js App Router (SSR/SSG)
  • ✦ Real-time data dashboard
  • ✦ Manajemen lengkap semua entitas
⚙️

REST API Backend

API RESTful dibangun dengan Python Flask, dilengkapi autentikasi JWT, migrasi database dengan Alembic, dan dokumentasi API lengkap.

  • ✦ JWT Authentication
  • ✦ Database migrations (Alembic)
  • ✦ Docker-ready deployment
🤖

ML Service

Layanan machine learning terpisah yang menganalisis pola setoran untuk mendeteksi anomali dan memberikan skor risiko partisipasi setiap anggota.

  • ✦ Anomaly detection model
  • ✦ Participation risk scoring
  • ✦ Real-time inference API
